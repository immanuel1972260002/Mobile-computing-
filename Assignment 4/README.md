# Assignment 4 — Mobile Computing Design

This assignment is intentionally **design-only**. The submission instructions prohibit source code, IDEs, emulators and SDKs. Evidence is therefore organised as written specifications, architecture patterns, test data, scenario traces and expected outputs.

## Contents

- `Answers_Q1-Q6.md` — complete answers for Tasks 1–6, including the compulsory RuralCare design challenge
- `patterns/Architecture_and_Design_Patterns.md` — layered architecture, push path, launch dependency, power-state, offline sync and security patterns
- `data/Test_Data_and_Cases.md` — platform comparison inputs, sample record schema, synchronisation vectors, security regression cases and power test inputs
- `results/Expected_Outputs_and_Desk_Checks.md` — expected results, desk-check traces, adversarial test conclusions and acceptance criteria

## Important design note

No executable source files are included because the assignment explicitly states that source code is not accepted. The “implementation” evidence is represented using structured design notation, tables, ordered procedures and testable expected outcomes.
