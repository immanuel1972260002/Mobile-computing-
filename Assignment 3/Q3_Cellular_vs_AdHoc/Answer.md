Q3 – Cellular Networks versus Ad Hoc Wireless Networks (7 marks)

**Answer:** A cellular network is infrastructure-based. Mobile devices communicate through base stations, which connect to a core network. Coverage is divided into planned cells; mobility is supported by handoff between base stations. Routing and resource management are largely infrastructure-assisted. It offers broad managed coverage and supports public mobile services, but depends on functioning infrastructure.

An ad hoc network is infrastructure-less. Nodes communicate directly or through multiple peer nodes. Each node may act as both host and router. Topology changes as nodes move; distributed routing discovers and maintains multi-hop paths. It can be deployed rapidly for disaster relief, military and temporary field communication, but routes and connectivity may be unstable.

| Parameter | Cellular | Ad hoc |
|---|---|---|
| Infrastructure | Base stations/core network | No fixed infrastructure |
| Communication | Through base station | Direct or multi-hop peer links |
| Routing | Infrastructure-assisted | Distributed |
| Mobility | Cellular handoff | Route discovery/repair |
| Topology | Planned cells | Dynamic |
| Scalability | Broad managed coverage | Depends on node density and routing overhead |
| Failure | Infrastructure failure may disrupt service | Alternate peer routes may exist |
| Applications | Public voice/data | Disaster, military, temporary networks |

**Decision:** For a disaster area with unavailable fixed infrastructure, choose an ad hoc network because nearby rescue devices can form multi-hop paths without base stations. Redundant paths and route repair improve resilience.
